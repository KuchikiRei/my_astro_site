# 常见文件后缀


## csv 
Comma-Separated Values(逗号分隔值)，没有任何格式的 Excel 表格。  
**特点:** 每一列用 **,(逗号)** 分隔。每一行表示一条数据。  
**优势:** 文件小，打开速度快，所有编程语言都支持。

---

## tsv
Tab-Separated Values（制表符分隔值），一种纯文本表格数据格式，类似 CSV，但是使用 Tab`(\t)`制表符 分隔列。

**特点:**
- 每一列使用 Tab（制表符） 分隔，而不是逗号。
- 每一行表示一条数据记录。
- 本质上也是一个没有格式的 Excel 表格。
- 文件后缀通常为 .tsv。
